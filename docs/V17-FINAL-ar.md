# الإصدار ١٧ — الحزمة النهائية

- الشعارات في منتصف الشاشة، واسم المدرسة أسفلها. أُزيلت العلامة الصغيرة داخل الفراغ الأبيض لشعار طويق دون تغيير الرسم الرئيسي.
- العرض اليومي والوسائط يملآن نافذة العرض بما فيها شاشة Mac بنسبة 16:10، دون الأشرطة الخارجية السوداء. «تغطية» هي الملاءمة الافتراضية للوسائط الجديدة؛ «احتواء» يبقى متاحًا لمن يريد الملف كاملًا مع فراغ حوله.
- في الرئيسية، تحت إعدادات الوسائط: صوت، تكرار أو التوقف عند آخر إطار، وإظهار أزرار الفيديو اختياريًا. المعاينة صامتة. قد يمنع المتصفح الصوت التلقائي؛ تظهر ضغطة لتشغيل الصوت على التلفزيون. لا يمكن تجاوز سياسة Safari/Chrome دون تفاعل المستخدم.
- لا يوجد حد حجم ثابت في التطبيق لملفات الفيديو وGIF. الخادم المحلي يكتب الرفع مباشرة إلى القرص بدل تجميعه في الذاكرة؛ المساحة المتوفرة وقيود الجهاز ما زالت مطبقة. ضغط الصور إلى حجم مناسب لشاشة 4K مستمر.
- Supabase يفرض حدود المشروع والخطة حتى لو أُلغي حد الحاوية المخصص. طبّق الترحيلين 0003 و0004 للوسائط، واضبط حدود التخزين المناسبة في مشروعك؛ لا توجد استضافة سحابية غير محدودة فعليًا. الرفع مباشر إلى Supabase ولا يمر بدالة Netlify.
- صفحة الدخول /login ضمن تحديث الواجهة العربية، مع إظهار/إخفاء كلمة المرور، حقول مناسبة للهاتف، ورسائل أخطاء الاتصال. مصادقة Supabase وحماية الإدارة باقية في بناء السحابة. حزمة Mac التجريبية تدخل تلقائيًا كما كانت.

## شاشتان على نفس الكمبيوتر

١. اختر «توسيع الشاشة» في إعدادات macOS أو Windows، بدل عرض نسخة متطابقة على الشاشتين.
٢. من «الشاشات» أنشئ لوحة محتوى لكل شاشة فعلية، ثم أنشئ رابط العرض المعتاد.
٣. اختر اسم رابط النافذة مثل tv أو tv2 ثم «إنشاء رابط نافذة الشاشة».
٤. استخدم «فتح نافذة شاشة مستقلة». افتح نافذة لكل شاشة، واسحبها إلى الشاشة المطلوبة ثم فعّل ملء الشاشة. قد يتعامل المتصفح مع طلب النافذة بحسب إعداداته؛ يمكن أيضًا فتح الرابط يدويًا في نافذة جديدة.

تبقى روابط /display و/display2 موجودة. روابط /tv2 وما بعدها تستخدم نفس آلية العرض المحمي برمز وتخزين مستقل؛ لا تتطلب كمبيوترًا أو حسابًا إضافيًا. اسم المسار لا يختار منفذ HDMI تلقائيًا؛ توزيع النوافذ مهمة نظام التشغيل.

## البناء والرفع

GitHub: ارفع المصدر، دون .env أو node_modules أو dist-local/data. البناء `npm ci` ثم `npm run build`. إعداد Netlify المرفق ينشر dist ويوجّه مسارات الدخول والعرض إلى React. إعدادات Supabase البيئية تبقى كما هي؛ لا تستخدم محول الاختبار المحلي في نشر السحابة.

Mac: فك الحزمة وشغّل Start-Mac.command مع Node.js 22 أو أحدث. يفتح عنوان IP الشبكة ويطبعه للهاتف. للاحتفاظ بمحتوى v16، أوقف الخادمين وانسخ مجلد data القديم إلى الحزمة الجديدة قبل التشغيل.

هذه حزمة المصدر؛ رفعها إلى GitHub لا يؤكد نجاح نشر Netlify. اختبارات الحساب الحقيقي وصلاحيات تشغيل الصوت على Mac/iPhone الفعلي تحتاج تجربتك على الجهاز.

فحص الحزمة: نجح بناء الإنتاج وTypeScript وlint، واختبارات الحصص واللوحة الستة. نجح اختبار متصفح محلي للشعار في المركز، وتشغيل فيديو بصوت ثم توقفه عند النهاية وإعادة تكراره عند تغيير الخيار، وملء العرض اليومي والوسائط لنافذة 1440×900 دون أشرطة خارجية، وفتح رابط tv2، ورفع متدفق بحجم ٥١ ميجابايت يتجاوز الحد السابق. نجح فحص صفحة الدخول العربية وتبديل إظهار كلمة المرور وعرض الهاتف بلا تمرير أفقي. اختبار الدخول لا يستخدم حساب المدرسة الحقيقي؛ لا يشمل اعتماد تسجيل الدخول الفعلي أو نشر Netlify في حسابك.
