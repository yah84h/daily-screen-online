# خلفية الحصص ولوحة التميز

من لوحة الإدارة افتح **خلفية الحصص**. اختر **الخلفية والساعة والحصص** ثم اضغط **حفظ الخلفية ولوحة التميز**. التشغيل يدوي؛ لا يتبدل الوضع عند بدء الحصة. اختر **المحتوى اليومي** للعودة إلى الإعلان المعتاد. القوالب القديمة تبقى في وضع المحتوى اليومي حتى تختار خلاف ذلك.

## لوحة التميز

- فعّل **إظهار اللوحة** واكتب عنوانًا وعبارة تعريفية من اختيارك: نجوم الأسبوع، المتفوقون في الدرجات، أو غيرها.
- أضف اسم الطالب والإنجاز/الصف. الصورة اختيارية وتقبل PNG الشفاف وJPEG وWebP، مع الضغط الحالي للصور.
- تدعم القائمة حتى ٣٠ طالبًا؛ تظهر صورتان/اسمان في كل صفحة وتنتقل الصفحات بهدوء. يمكن تغيير مدة الصفحة.
- احذف الطالب أو صورته مستقلًا. إخفاء اللوحة يحتفظ بالقائمة والصور عند الحفظ.
- الحفظ خاص بالشاشة المختارة. كل تلفزيون مربوط بهذه الشاشة يستقبل نفس القالب من Supabase، دون تغيير موضوع اليوم أو مسودته.

الصور تستخدم حاوية `media` الحالية ومجلد `content`، بنفس سياسات الوصول الموجودة في المشروع. هذه روابط عامة مثل الصور اليومية الحالية؛ إخفاء اللوحة لا يحذف الملف من التخزين. لا ترفع صورة طالب إلا وفق سياسة المدرسة وموافقتها على استخدامها.

## الساعة والحصص

التوقيت هو جدة، عبر `Asia/Riyadh`. الساعة بنظام ٢٤ ساعة، وتتغير أرقامها والحصة بانتقال قصير دون وميض. يمكن تعطيل الانتقالات؛ تفضيل الجهاز لتقليل الحركة محترم كذلك.

أوقات الحصص قابلة للتعديل من القسم المطوي، وتُعرض حقول الساعة/الدقيقة باتجاه يسار إلى يمين لتجنب قلب الأرقام في الواجهات العربية. الخميس ينتهي بعد السادسة، وبقية أيام الدراسة بعد السابعة. قبل البداية: **حياكم الله**. الفاصل بين الثالثة والرابعة: **الفسحة**. نهاية اليوم: **الصلاه / صرفه**. الجمعة والسبت لا تعرضان حصصًا. لا تُعرض أسماء مواد دراسية.

## العرض والتخزين

الخلفية SVG أصلية وليست فيديو مضغوطًا، وتتدرج إلى 4K دون بكسلة. الافتراضي شعار وزارة التعليم يسارًا وشعار أكاديمية طويق يمينًا بفاصل رأسي، واسم «مدارس الموهوبين التقنيه بجدة» أسفلهما. يمكن تعديل اسم الخلفية أو اختيار شعار المدرسة المرفوع من تبويب الخلفية. الشعارات مرفقة محليًا مع مصادرها في `public/branding/SOURCES.md` وتُخزّن للعمل دون اتصال. الخلفية البيضاء تملأ نافذة التلفزيون، بما فيها النوافذ غير المطابقة تمامًا لـ16:9.

إعدادات الخلفية والقائمة محفوظة داخل `screens.template` بصيغة JSON، دون ترحيل قاعدة بيانات جديد. التحديث يستخدم مسار البث الحالي مع جلب دوري احتياطي كل ٣٠ ثانية. لا يمنع تعذر البث إكمال الحفظ في قاعدة البيانات. تُحفظ صور الطلاب ضمن نسخة IndexedDB المحلية للتلفزيون بعد تنزيلها بنجاح، والخط المرفق متاح دون اتصال. قبل أول تنزيل ناجح للصورة قد يظهر حرف اسم الطالب عند انقطاع الاتصال.

المكتبة التقنية موضحة في [TECH-QUOTES.md](./TECH-QUOTES.md). الروابط للمصادر اختيارية؛ اختيار النصوص وعرضها لا يحتاجان شبكة.

## التحقق

```sh
npm ci
npm run build
npm run lint
node --test tests/loop.test.mjs
```

اختبر الربط والحفظ والبث مع مشروع Supabase التجريبي قبل دمج الفرع أو النشر. الاختبارات المحلية لا تعدّل قاعدة بيانات الإنتاج.

لاختبار المتصفح محليًا ببيانات وهمية (بلا وصول إلى Supabase الحقيقي): ابنِ التطبيق باستخدام `VITE_SUPABASE_URL=https://mock.school.test VITE_SUPABASE_ANON_KEY=local-test-only npm run build`، ثم شغّل `npm run preview -- --host 127.0.0.1 --port 5173 --strictPort` في نافذة منفصلة، وبعدها شغّل `npm run test:browser-loop`. يستخدم الاختبار Chromium من Playwright؛ ثبّته أولًا بـ`npx playwright install chromium`، أو حدّد مسار Chromium عبر `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.
