# صور خلفية متعددة — v18

من «القوالب» افتح «الخلفية والمؤثرات» ثم «إضافة صور متعددة». يمكنك اختيار عدة صور من مكتبة الهاتف في مرة واحدة. تُضغط الصور إلى حجم مناسب لعرض 4K، مع دعم JPG وPNG وWEBP.

- تشغيل الشرائح أو إخفاؤها دون حذف الصور.
- تقديم الصور وتأخيرها، تكرار صورة أو حذفها.
- وقت افتراضي للصور، ووقت مستقل لكل صورة عند الحاجة.
- تلاشي هادئ، انزلاق ناعم، اقتراب حالم، أو تبديل مباشر.
- ضبط مدة الانتقال، والتكرار بعد آخر صورة، وإيقاف التبديل التلقائي.
- لكل صورة: احتواء/تغطية/تمدد، موضع أفقي ورأسي، تكبير، وإضاءة. المعاينة المصغرة تُظهر نتيجة تعديل الموضع.
- للخلفية كلها: طبقة لون بشفافية متدرجة، نعومة، وتشبع ألوان. توجد إعدادات جاهزة: طبيعي، حالم، وتباين واضح بحسب لون النص الحالي.

بعد التعديل اضغط «حفظ القالب» أو انشر من الرئيسية. تصل الإعدادات إلى أجهزة الشاشة المرتبطة. تعمل الصور خلف المحتوى اليومي، وكذلك خلف واجهة الساعة والحصص؛ لا تغيّر وضع صورة/فيديو فقط. تبقى الخلفية الثابتة القديمة متاحة عند إيقاف الشرائح. طبقة الشعار والساعة والطلاب والنصوص لا تتحرك مع الشرائح.

يُحمّل الإطار التالي قبل إظهاره، وتُتجاوز الصور التي تعذّر تحميلها. إعداد تقليل الحركة في الجهاز يلغي حركات الانتقال. تحفظ صور الشرائح ضمن النسخة المحلية الأخيرة للشاشة، بحسب مساحة التخزين المتوفرة في المتصفح. لكل شاشة قائمة وإعدادات مستقلة داخل قالبها الحالي، دون جداول أو ترحيلات Supabase إضافية.

الأزرار تعمل باللمس؛ اضغط اسم الصورة لفتح إعداداتها. احتواء الصورة قد يترك فراغًا حولها للحفاظ عليها كاملة، ويمكن اختيار التغطية لملء المساحة.

الاختبارات: `npm run test:slideshow`، وبعد `npm run build:local` استخدم `npm run test:slideshow-browser` مع متصفح Playwright مثبت. لا تستخدم اختبارات الواجهة بيانات المدرسة؛ تُنشئ نسخة خادم مؤقتة وتحذفها عند الانتهاء.
