# الإصدار ٢٧

اسم المدرسة الافتراضي: الموهوبين التقنية الثانوية بجدة - بنين. عند تشغيل النسخة المحلية تُحدّث الأسماء الافتراضية القديمة المعروفة فقط، وتُحفظ الأسماء المخصصة. ٢٥ لوحة ألوان في القوالب وخلفية الحصص، بينها بنفسجي داكن ووردي ليلي وتوتي، وجميعها تشمل ألوان مؤشر الحصة.

استُبدل صندوق الاقتباس في خلفية الحصص بشريط أخبار بعرض الشاشة يتحرك من اليمين إلى اليسار. مكتبة الومضات القديمة باقية في الإدارة. إعداد تقليل الحركة يوقف التحريك ويتيح التمرير يدويًا.

مصادر الأخبار التقنية هي واجهة GitHub REST API الرسمية لمستودعات nodejs/node وmicrosoft/vscode وmicrosoft/TypeScript. تعرض أخبار الإصدارات المستقرة مع العنوان الأصلي والمصدر والتاريخ، وليست خدمة أخبار صحفية شاملة أو ترجمة آلية. التحديث كل ١٥ دقيقة ويخضع لتوفر الشبكة وحدود GitHub. عند تعذر الاتصال تُعرض آخر بيانات محفوظة، دون اختلاق أخبار. لا يلزم مفتاح API.

## إضافة خبر مدرسي

افتح /news على نفس عنوان الإدارة، مثال http://192.168.1.20:8080/news. اختر الشاشة وأضف نصًا (حتى ٣٠ خبرًا، ٣٠٠ حرف لكل خبر)، ويمكن إخفاؤه أو حذفه أو تحديد انتهاء تلقائي بتوقيت جدة. أخبار المدرسة تظهر أولًا. يمكن إيقاف الأخبار التقنية أو الشريط بالكامل. الخبر يُنشر مباشرة دون تغيير القالب أو الصور أو الحصص.

محليًا: يلزم رمز صلاحية خاص بالنشر، يظهر في نافذة تشغيل الخادم بجوار Staff PIN. ملف data/news-access.json يحتفظ بالرمز على جهاز التشغيل فقط؛ لا تشاركه علنًا. لإعادة توليده أوقف الخادم واحذف هذا الملف وحده ثم أعد التشغيل. ثماني محاولات خاطئة توقف المحاولات عشر دقائق. لوحة الإدارة المحلية الأصلية غير محمية بتسجيل دخول وتظل مخصصة لشبكة المدرسة الموثوقة؛ رمز الأخبار ليس نظام حماية شاملًا لكل الإدارة.

سحابيًا: /news يتطلب حساب مدرسة مسجل الدخول؛ سياسة المشروع الحالية تعتبر كل حساب مسجل مسؤولًا. أبقِ التسجيل الذاتي مغلقًا وأنشئ حسابات المعلمين المصرح لهم يدويًا. طبّق supabase/migrations/0005_news.sql قبل استخدام الأخبار على Supabase. لا يوجد مفتاح خدمة أو حسابات مضمّنة. لم نطبق الهجرة على مشروعك الحقيقي ولم ننشر أو نرفع شيئًا إلى GitHub.

## الترقية والتشغيل

انسخ مجلد data السابق إلى النسخة الجديدة قبل التشغيل، ثم استخدم Start-Mac.command أو Start-Windows.bat حسب النظام. يحتاج الحاسوب إلى Node.js 22 أو 24، والهاتف على الشبكة نفسها. خبر المدرسة محفوظ مع قالب الشاشة ومتاح دون اتصال ضمن آخر حالة محفوظة؛ الصور وتوقيت الحصص وأحجام العناصر ومؤشر الامتلاء محفوظة.
