# الإصدار ٢٤

- عداد صغير تحت الساعة: المتبقي لانتهاء الحصة بالدقائق والثواني مع شريط يتناقص. يظهر أثناء الحصص فقط، حسب الجدول المحفوظ وتوقيت جدة، ويختفي أثناء الفسحة وخارج اليوم الدراسي.
- إصلاح قناع SVG الذي كان يقص شعار طويق بالكامل. بقيت المنطقة الداخلية شفافة دون الرقعة البيضاء.
- فصل قوائم صور ملء الشاشة عن شرائح الخلفية، مع الحفاظ على الصور القديمة وتحويلها عند التبديل من الوضع القديم.
- زر «استعادة الخلفية المتحركة» في خلفية الحصص لإيقاف صور الخلفية عند الحاجة، دون حذف الصور أو تغيير الألوان والطلاب وصور الوسط. احفظ أو انشر لتطبيقه.

## تشغيل ماك

فك الضغط كاملًا وشغّل Start-Mac.command. تحتاج Node.js 22 أو 24 على الماك فقط. افتح على الهاتف عنوان IP الذي يظهر، على الشبكة نفسها. عند الترقية احتفظ بمجلد data من نسختك السابقة وانقله قبل تشغيل النسخة الجديدة.

## المصدر والمعاينة الحية

من المصدر شغّل npm install ثم npm run dev:local. واجهة المعاينة على 5173 وتخزين التجربة المنفصل في local-test/data. لم تُرفع هذه النسخة إلى GitHub ولم تُنشر.
