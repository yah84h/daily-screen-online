# الاختبار على الماك من المصدر

افتح Start-Mac.command الموجود في المجلد الرئيسي للمشروع. يثبت اعتماديات الواجهة عند أول تشغيل، ويبني ملفات الموقع، ثم يشغّل الخادم المحلي ويفتح /admin. يحتاج Node.js 22 أو أحدث.

إذا فتحت المشغّل داخل local-test من نسخة المصدر، فإنه يوجهك إلى المشغّل الرئيسي تلقائيًا. لا تشغّل server.mjs يدويًا قبل تجهيز الواجهة. عند وجود الخادم نفسه قيد التشغيل، يعيد المشغّل فتحه بدل بدء خادم ثانٍ على المنفذ نفسه.

بيانات نسخة المصدر تبقى في local-test/data. بيانات الحزمة المستقلة تبقى في data داخل الحزمة. إعادة build:local لا تحذف مجلد data الموجود في dist-local. لا تخلط مجلدي البيانات أو تستبدلهما بنسخة فارغة.

لإيقاف خادم شغّلته من Terminal اضغط Control+C. بعد تعديل المصدر أو متغيرات الخادم، أوقفه ثم شغّله مجددًا. المنفذ الافتراضي 8080؛ يمكن تغييره بمتغير PORT.

لإعداد قدرات برو محليًا ضع رابط API الكامل في .env.local بالمجلد الرئيسي باسم QUDRAT_PRO_LEADERBOARD_URL. هذا الملف خاص ومُستثنى من Git ولا يدخل حزمة الواجهة. المشغّل الرئيسي يقرأه للخادم؛ لا تستخدم بادئة VITE_.

جرى إصلاح ENOENT الخاص بـ local-test/web/index.html: خادم نسخة المصدر يقرأ الواجهة المبنية من dist-local/web، والحزمة المستقلة تقرأ web داخل مجلدها. إذا لم تتوفر الواجهة، تظهر تعليمات واضحة بدل مسار ملف داخلي.
