# تشغيل شاشة المدرسة على Windows

Windows هو جهاز التشغيل الفعلي؛ Mac مخصص للاختبار فقط.

1. ثبّت Node.js LTS (الإصدار 22 أو أحدث) وMicrosoft PowerPoint لسطح المكتب. افتح PowerPoint مرة واحدة وتأكد من تفعيله. PowerPoint في المتصفح وحده لا يكفي.
2. فك ضغط حزمة Windows كاملة، ثم افتح Start-Windows.bat. لا تحتاج الحزمة الجاهزة إلى npm أو بناء الموقع. عند تنزيل المصدر من GitHub، افتح الملف نفسه من المجلد الرئيسي؛ سيجهّز التبعيات ويبني الموقع تلقائيًا أول مرة.
3. اترك نافذة الخادم مفتوحة. افتح رابط Admin المطبوع، واختر «ملف PowerPoint»، وارفع PPTX ثم انشره.
4. افتح رابط Display على شاشة العرض. تحكم من الهاتف عبر رابط Admin وعنوان IPv4 الخاص بجهاز Windows، على الشبكة نفسها. عند مطالبة جدار حماية Windows، اسمح لـNode بالوصول على الشبكة الخاصة الموثوقة.
5. مؤشر العروض يعمل عبر Page Up/Page Down عندما تكون نافذة العرض محددة. أزرار الهاتف والأولى والأخيرة والشاشة السوداء تعمل كما في الاختبار على Mac.

احتفظ بمجلد data عند تحديث الحزمة. لا تستبدله ببيانات اختبار من جهاز آخر. لا يتطلب PowerPoint تثبيت Python أو LibreOffice أو Poppler على Windows. يجب تشغيل الخادم في جلسة مستخدم Windows العادية التي ثُبّت وفُعّل فيها PowerPoint، وليس كخدمة غير تفاعلية.

لإعداد مصدر قدرات برو، ضع المتغير QUDRAT_PRO_LEADERBOARD_URL في ملف .env بجانب start-server.mjs في الحزمة، أو في المجلد الرئيسي لنسخة المصدر، ثم أعد تشغيل الخادم. لا ترفع ملف .env إلى GitHub.

اختبارات CI على Windows تتحقق من سكربت PowerShell، وصحة ملف PPTX ورفض الملفات التالفة، وبناء الحزمة. تشغيل Microsoft PowerPoint نفسه يحتاج جهاز Windows مع Office؛ لا يتوفر Office على منفّذ CI العام.
