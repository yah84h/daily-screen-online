# تحديث واجهة المدرسة

تستخدم لوحة التحكم ألوان v13 الافتراضية: الخلفية ‎#f2f6ff، النص ‎#254d80، واللون المميز ‎#4b91f7، مع خط المدرسة. القوالب المحفوظة مسبقًا لا تُحذف ولا تُستبدل تلقائيًا: اختر «هوية المدرسة الأصلية» في القوالب ثم احفظ لتطبيقها.

## الإضافات

- محرر v13: ٨ توزيعات للعناصر، هوية المدرسة الأصلية و١٠ مجموعات ألوان، تحريك باللمس، مقابض تغيير الحجم، تراجع، وتحريك دقيق بالأزرار أو المنزلقات.
- الألوان الجاهزة تغيّر الألوان فقط؛ توزيعات العناصر تغيّر المواضع والأحجام فقط. الصور والطلاب والمواعيد تبقى محفوظة.
- عرض وارتفاع لوحة التميز بمنزلقين ضمن المساحة الفارغة أعلى اليمين. المعاينة مباشرة، والحفظ لكل شاشة.
- «عبارة نهاية اليوم» والعبارة أسفلها قابلتان للتعديل في خلفية الحصص. لا يتغير سلوك الخميس أو الفسحة.
- أوضاع يومي / وسائط فقط / خلفية حصص. اختيار الوضع وحفظه يدوي؛ لا انتقال تلقائي عند بداية الحصص.
- تشغيل MP4 / WebM / GIF أصلي صامت ومتكرر، مع احتواء / تغطية / تمدد.
- الاحتفاظ بالمواضيع والجدولة والسجل وQR والربط والشاشات المتعددة والاقتباسات التقنية والصور الاختيارية.

## GitHub وNetlify

هذه الملفات مصدر جاهز للرفع إلى مستودعك، وليست تأكيدًا على رفعها أو نشرها.

1. ثبّت Node.js 22 أو 24 وشغّل `npm ci`.
2. `npm run build` يتحقق من TypeScript ويبني `dist`؛ إعداد Netlify موجود.
3. استخدم إعدادات Supabase الحالية. طبّق `supabase/migrations/0003_media_video.sql` في مشروعك لدعم ملفات الفيديو وGIF حتى ٥٠ ميجابايت. الترحيل لا يحذف الصور أو السياسات أو المحتوى.
4. إعدادات القوالب الجديدة تحفظ داخل JSON الحالي، ولا تحتاج جداول جديدة.
5. `npm run test:loop` لا يحتاج اتصالًا بالمدرسة. لا ترفع `.env` أو `node_modules` أو `dist-local/data`.

## تجربة Mac المحلية

`npm run build:local` ينشئ `dist-local` بخادم محلي وبيانات تجريبية. بعد ذلك لا يحتاج التشغيل إلى npm أو Supabase. شغّل `Start-Mac.command` أو `node server.mjs` من مجلد الحزمة. يتطلب Node.js 22 أو أحدث.

للهاتف: أوقف الخادم الأول ثم شغّل `Phone-Test-Mac.command`، وافتح عنوان الشبكة المطبوع في Safari على نفس الشبكة. الخادم التجريبي بلا تسجيل دخول، ولا يتصل ببيانات المدرسة. تبقى التغييرات في مجلد `data` على جهاز Mac، وتتشاركها الأجهزة المتصلة به. لا تفتح index.html من تطبيق الملفات.

## فحص هذه الحزمة

نجح بناء الإنتاج وفحص TypeScript، وفحص التنسيق البرمجي، واختبارات حدود الحصص والفسحة والخميس ونص الصرفة المخصص. فُحصت لوحة الإدارة بقياس 390×844 وعرض التلفزيون بقياس 3840×2160 في Chromium: حفظ القالب وهوية المدرسة، حفظ أبعاد اللوحة، استمرارية الإعدادات بعد إعادة التحميل، التزامن الفوري، رفع PNG، نشر صورة كاملة، وتشغيل MP4 صامت ومتكرر مع طلبات أجزاء الملف (HTTP 206).

هذه اختبارات محلية. لا تعني نجاح نشر Netlify أو تشغيلها على جهاز Mac/iPhone فعلي؛ استخدم حزمة Mac لتجربة Safari والشبكة لديك. لم تُغيَّر بيانات المدرسة أو إعدادات GitHub وNetlify عن بُعد.
