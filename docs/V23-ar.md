# الإصدار ٢٣

من الرئيسية اختر «صورة / فيديو فقط»، ثم من نوع الوسائط اختر «صورة واحدة / فيديو» أو «صور متعددة · عرض شرائح». يمكن إضافة عدة صور من الهاتف وتعديل ترتيبها ومدتها والانتقالات والملاءمة والموضع، ثم النشر من نفس الصفحة. يظهر التلفزيون الصور فقط بملء الشاشة. تبقى خيارات عرض الشرائح السابقة متاحة.

التبديل بين النوعين لا يحذف الصور أو الفيديو المحفوظ. الإعدادات والصور تُحفظ ضمن قالب الشاشة وتدعم آخر نسخة دون اتصال حسب مساحة المتصفح. لا يوجد تغيير على خلفية الحصص أو صور وسط الشاشة.

احتفظ بمجلد data عند الترقية وشغّل Start-Mac.command على ماك مثبت عليه Node.js 22 أو 24. لم تُرفع هذه النسخة إلى GitHub.
