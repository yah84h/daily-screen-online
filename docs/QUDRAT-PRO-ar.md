# قدرات برو — لوحة المتصدرين الأسبوعية

## الاستخدام

من لوحة الويب افتح **خلفية الحصص → لوحة التميز**، ثم اختر **قدرات برو** من «مصدر لوحة التميز» وفعّل اللوحة. اختر العربي أو الإنجليزي أو التبديل بينهما، ثم احفظ الخلفية ولوحة التميز.

خيار «إبراز الثلاثة الأوائل في الأعلى» يعرض منصة ثابتة للأوائل، مع انتقال بقية قائمة العشرة في صفحات من طالبين أو ثلاثة أو أربعة. يمكن اختيار مدة الصفحة من ٦ إلى ٣٠ ثانية. عند تعطيل المنصة تصبح القائمة كلها صفحات. شعار قدرات برو المقدم من صاحب المشروع يظهر أعلى اللوحة، وتبقى ألوان المدرسة قابلة للتخصيص. اختيار قدرات برو لا يمسح الطلاب المدخلين يدويًا؛ يمكن العودة إليهم باختيار المصدر اليدوي.

البيانات تشمل الاختبارين اللذين يعيدهما المصدر (`weekly` و`gat`) والعناوين والرتب والدرجات الفعلية. لا نخلط رقم الأسبوع العام مع اسم الاختبار؛ يُعرض عنوان الاختبار القادم من المصدر. لا توجد أسماء أو درجات تجريبية في مسار الإنتاج.

## إعداد Netlify — مطلوب قبل استخدام المصدر الحقيقي

أضف متغير بيئة **للخادم/الوظائف فقط** باسم:

```
QUDRAT_PRO_LEADERBOARD_URL
```

قيمته رابط `public-leaderboard` الكامل المقدم لك، بما فيه معامل `key`. لا تستخدم بادئة `VITE_` ولا تضع المفتاح داخل `screens.template` أو ملف الواجهة. لم يُضمّن المفتاح في المستودع أو حزمة الواجهة.

انشر المصدر المعتاد باستخدام `npm ci` ثم `npm run build`. وظيفة `netlify/functions/qudrat-pro.mjs` تقرأ الرابط من البيئة، والتوجيه في `netlify.toml` يربط `/api/qudrat-pro` بهذه الوظيفة. لا يلزم ترحيل Supabase جديد؛ الإعدادات محفوظة داخل JSON القالب الحالي. بعد النشر، تحقق من أن `/api/qudrat-pro` يعيد 200، ثم احفظ اختيار قدرات برو من اللوحة.

إعداد المتغير ورفع الكود إلى موقع الإنتاج لم يتمّا أثناء هذه المهمة. اختبار وظيفة الخادم مع الرابط الحقيقي نجح وأعاد ١٠ طلاب للعربي و٣ للإنجليزي وقت التحقق.

## التحديث والعمل عند الانقطاع

يحدث التحديث كل خمس دقائق. تحقّق النتائج قبل عرضها، ويحتفظ الخادم والواجهة بآخر رد صالح. عند فشل التحديث تظهر عبارة «آخر نتائج محفوظة» ووقت التحديث بدل الادعاء بأنها نتائج حية. نتيجة فارغة صالحة لأسبوع جديد تستبدل الأسبوع القديم؛ لا تُكرر أسماء لملء القائمة.

التلفزيون يطلب عنوانًا من الموقع نفسه، ولا يحصل على مفتاح المصدر أو يتصل مباشرة بمشروع Supabase الخاص بقدرات برو. الطلبات مع إعادة توجيه أو استجابة أكبر من ١ ميغابايت تُرفض.

## التطوير المحلي

النسخة المحلية الصارمة الموزعة مع تطبيق الآيفون تبقى دون اتصال خارجي، ولذلك ترفض المصدر برسالة `OFFLINE_ONLY`. لا نغيّر هذا السلوك بصمت. لتجربة مصدر الإنترنت على خادم تطوير محلي عادي، مرر المتغير السابق إلى عملية الخادم دون تفعيل `offlineOnly`، أو اختبر العرض ببيانات وهمية كما في الاختبارات.

```sh
npm run test:qudrat
npm run build
npm run lint
npm run build:local -- --offline-only
npx playwright install chromium --only-shell
npm run test:qudrat-browser
```

اختبار المتصفح يستخدم بيانات وأسماء تجريبية صريحة فقط. يفحص حفظ المصدر مع بقاء الطلاب اليدويين، والمنصة الثابتة، وتبديل صفحات البقية، والاختبار الإنجليزي بثلاثة طلاب فقط، ونتائج الانقطاع المخزنة، وتقليل الحركة، ومقاسات 4K والماك والهاتف. لا يغير بيانات المدرسة الحقيقية.
