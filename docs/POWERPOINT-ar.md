# PowerPoint على خادم Windows

من الرئيسية اختر «ملف PowerPoint»، ثم «رفع ملف PowerPoint». يقبل PPTX حتى 100 ميجابايت و200 شريحة. انتظر انتهاء الرفع والتحويل، ثم اضغط «نشر على الشاشة». لا تتغير الشاشة المنشورة عند رفع مسودة جديدة حتى تنشرها.

بعد النشر تظهر أزرار التحكم من الهاتف: التالي والسابق، الأولى والأخيرة، اختيار شريحة من الصور المصغرة، والشاشة السوداء. افتح لوحة الإدارة على الهاتف عبر عنوان الكمبيوتر في شبكة Wi-Fi نفسها. التنقل مشترك بين الأجهزة التي تعرض الشاشة نفسها. عروض الشاشات الأخرى مستقلة.

على نافذة الشاشة الكبيرة: Page Down أو السهم الأيمن أو المسافة للتالي؛ Page Up أو السهم الأيسر للسابق؛ Home وEnd للأولى والأخيرة؛ B أو النقطة لإخفاء العرض وإظهاره؛ F5 لملء الشاشة. ضع التركيز على نافذة العرض. مؤشر PowerPoint الذي يرسل Page Up/Page Down يعمل بهذه الطريقة؛ لم يُختبر مؤشر مادي بعينه. لا يتجاوز التنقل بداية العرض أو نهايته.

تُحوّل الشرائح إلى صور JPG عالية الدقة على خادم المدرسة، مع احتواء الشريحة كاملة والمحافظة على نسبتها. لا تُشغل حركات PowerPoint أو الصوت والفيديو المضمنين أو وسائط خارجية. قد تختلف بعض الخطوط إن لم تكن مثبتة على الخادم. على Windows يلزم Microsoft PowerPoint لسطح المكتب مثبتًا ومفعّلًا، مع فتحه مرة واحدة قبل التجربة. يستخدم الخادم Windows PowerShell المدمج، ولا يتطلب Python أو LibreOffice أو Poppler. على Mac الاختباري فقط تُستخدم LibreOffice وpdftoppm وPython 3.

الرفع والتحكم محميان بصلاحية المحتوى اليومي، ويُسمح لجهاز عرض مقترن بالتحكم في شاشته فقط. يحفظ النشر العرض، بينما تُحفظ الشريحة الحالية في ذاكرة الخادم؛ بعد إعادة تشغيل الخادم يبدأ العرض من الأولى. نسخة Netlify المنشورة لم تُعدّل؛ التحويل والتحكم يعملان عبر خادم المدرسة المحلي على Windows؛ Mac للاختبار فقط.

الاختبارات: npm run test:presentation وnpm run test:presentation-browser.

## عناصر التحكم وصوت الخلفية

تظل أزرار ملء الشاشة والتنقل مخفية عند استخدام لوحة المفاتيح أو مؤشر العروض، وتظهر لمدة قصيرة عند تحريك الماوس.

من الرئيسية، أضف «صوت / موسيقى الخلفية» برفع ملف صوت أو لصق رابط Drive عام يسمح بالتنزيل، ثم انشر. الصوت يتكرر طوال الوقت عند تشغيله. على كل جهاز عرض، اضغط S أو انقر مرتين لفتح الإعدادات، ثم اختر «تشغيل صوت الخلفية» واضبط المستوى. يبدأ كل متصفح جديد والصوت متوقف، وتُحفظ حالة التشغيل والمستوى محليًا لذلك الجهاز. قد يتطلب المتصفح ضغطة تشغيل بعد إعادة التحميل للسماح بالصوت. رفع الملفات يدعم MP3 وM4A وWAV وOGG وFLAC حتى 100 ميجابايت، مع مراعاة حدود التخزين السحابي إن استُخدمت.
