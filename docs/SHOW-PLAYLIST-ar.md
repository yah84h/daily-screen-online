# قوائم الفيديو والصور والتحضير خلف الكواليس

في «صورة / فيديو» توجد «قائمة عرض · فيديوهات وصور متعددة». أضف روابط HTTPS مباشرة أو Drive عامة، أو ارفع عدة ملفات. أعد الترتيب بالأسهم، وحدد مدة الصور وتكرار القائمة ثم انشر.

لتجهيز العرض قبل المناسبة: أبقِ الشاشة في وضع المحتوى اليومي أو خلفية الحصص، وأضف القائمة وفعّلها ثم انشر. يبقى المحتوى العادي ظاهرًا أثناء تجهيز القائمة. الشريط الزجاجي أعلى جهاز العرض يوضح التقدم ويختفي عند الانتهاء. بعد ذلك اختر وضع «صورة / فيديو» وانشر؛ تُستخدم الملفات المحلية الجاهزة. عند تحديث قائمة تعمل بالفعل، تستمر القديمة حتى يكتمل تجهيز الجديدة؛ فشل ملف يبقي القديمة مع رسالة صغيرة وزر إعادة المحاولة.

القائمة تقبل حتى ٣٠ ملفًا، بحد ٥١٢ ميجابايت للملف و٢ جيجابايت من الملفات الفريدة للقائمة. حفظ IndexedDB منفصل لكل متصفح وجهاز وموقع، ويحتفظ بعدة ملفات بدل مسح الفيديو السابق. مخزن القوائم محدود بـ٢ جيجابايت ويحذف الأقدم عند الحاجة. عند تعذر الحفظ بسبب مساحة الجهاز، يستمر التحضير للجلسة الحالية، وقد يعاد التنزيل بعد التحديث. بيانات المتصفح قد تُحذف تلقائيًا. لا يعني التخزين المحلي أن الربط والتحكم والتطبيق بالكامل يعمل دون إنترنت.

روابط Drive يجب أن تكون عامة مع السماح بالتنزيل. الروابط المباشرة يجب أن تسمح بالتنزيل عبر CORS. يتأكد الجهاز من إمكانية فتح الملفات قبل الانتقال. الصور تتحرك حسب مدتها، والفيديوهات حسب نهايتها، والتكرار يعود لأول ملف. السماح بالصوت قد يحتاج ضغطة على جهاز العرض.

إذا تغير الملف بنفس الرابط، افتح إعدادات التلفزيون وانقر «مسح ذاكرة قوائم الوسائط على هذا الجهاز» لإعادة تنزيله. هذا يمسح كاش قوائم هذا المتصفح فقط، ولا يحذف الملفات المرفوعة أو محتوى المدرسة. رابط جديد أكثر وضوحًا للإصدارات الجديدة.

يعرض الشريط نفسه حالة تجهيز PowerPoint وصوت الخلفية أيضًا. كاش PowerPoint مستقل؛ صوت الخلفية الحالي محضّر للجلسة فقط.

اختبار المتصفح: `npm run build:local` ثم `node tests/video-playlist-browser.mjs` بعد إعداد مسار متصفحات Playwright إن لزم.
