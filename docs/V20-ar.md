# الإصدار ٢٠

في «خلفية الحصص» افتح «صور وسط الشاشة» وأضف صورًا متعددة ثم فعّل العرض. اضبط الترتيب والمدة والانتقال والملاءمة ثم احفظ أو انشر من الرئيسية. الإيقاف يخفي الصور ولا يحذفها. الصور مستقلة عن شرائح الخلفية وشرائح ملء الشاشة وتُحفظ للعمل دون اتصال حسب مساحة المتصفح.

طويق أعلى اليسار ووزارة التعليم أعلى اليمين. استعيد وضوح حركة الخطوط والمكعبات؛ إعداد تقليل الحركة في الجهاز يبقى محترمًا.

لا يوجد رفع إلى GitHub أو نشر. احتفظ بمجلد data عند الترقية وشغّل Start-Mac.command على ماك مثبت عليه Node.js 22 أو 24.
