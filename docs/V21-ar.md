# الإصدار ٢١

صور وسط الشاشة أصبحت افتراضيًا ١٦:٩ وبعرض أكبر، مع ضبط العرض تلقائيًا لتجنب لوحة التميز. من «خلفية الحصص» اختر نسبة الأبعاد ١٦:٩ أو ٤:٣ أو ٣:٢ أو ١:١ أو ٩:١٦، وشكل مستطيل ناعم أو مستقيم أو دائرة أو بيضاوي. الدائرة تستخدم نسبة ١:١. تبقى ملاءمة كل صورة وموضعها قابلة للتعديل.

من «ألوان الخلفية والعناصر المتحركة» غيّر خلفية الشاشة والبطاقات والنصوص والساعة والحدود وكل لون من الخطوط والمكعبات. التعديلات تخص شاشة الحصص فقط وتُحفظ لكل شاشة. زر «استعادة ألوان المدرسة» يعيد الأبيض المزرق والألوان الأصلية. الخطوط والمكعبات رسومات متجهية متحركة وليست فيديو.

احتفظ بمجلد data عند الترقية. شغّل Start-Mac.command على ماك مثبت عليه Node.js 22 أو 24. لم ترفع هذه النسخة إلى GitHub ولم تُنشر.
