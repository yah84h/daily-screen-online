# تحديث ٣٢

- ٤٠ سؤالًا وجوابًا تقنيًا محفوظة دون اتصال، مع ٦ أسئلة مختلفة كل يوم حسب توقيت جدة. يظهر السؤال أعلى والإجابة أسفل في الشريط نفسه؛ محتوى تعليمي تحريري وليس اقتباسات منسوبة. توجد مراجع للتوسع ومعاينة أسئلة اليوم في صفحة الأخبار.
- رفع حد الأخبار المستوردة إلى ٢٤ خبرًا فريدًا من BBC Technology وArs Technica وMIT News، حسب ما توفره المصادر. لا تكرار لملء العدد؛ إعلانات المدرسة والأسئلة تضاف إلى الدورة.
- التحديث كل ٢٤ ساعة. حصة الترجمة المجانية محدودة؛ تترجم أول ٨ أخبار، وتبقى الأخبار الإضافية بنصها الأصلي بوضوح. لإتاحة الترجمة لجميع الأخبار ضع GOOGLE_TRANSLATE_API_KEY في إعدادات الخادم فقط، وتطبق رسوم وحصص مقدم الخدمة. لا تُرسل إعلانات المدرسة الخاصة إلى الترجمة.
- خمس لوحات داكنة إضافية: جمشت عميق، بترولي داكن، عنابي ملكي، سبج وذهب، وأردوازي وبنفسجي. المجموع ٣١ لوحة مشتركة بين المحرر اليومي والخلفية.
- توازن مواضع الشعارين: طويق يسار والوزارة يمين، بمركز بصري مشترك وهوامش متساوية. تحسين لمس إعدادات الأخبار والتفاف التبويبات في الهواتف.
- إعداد تجميع وظائف Netlify باستخدام esbuild، ورؤوس تحديث الصفحة والحماية، وملف GitHub Actions لاختبارات البناء مستقبلًا. لم يحدث رفع إلى GitHub أو نشر.

## التشغيل والتحديث
أوقف النسخة القديمة وانسخ مجلد data إلى مجلد النسخة الجديدة قبل التشغيل، واحتفظ بنسخة احتياطية. شغل Start-Windows.bat أو Start-Mac.command. يلزم Node.js 22 أو 24 على الحاسوب فقط؛ استخدم عنوان الشبكة للهاتف. الحساب Archo وكلمة المرور المحددة سابقًا، دون تفعيل أو تغيير إجباري. تبقى الحسابات والمحتوى والإعدادات محفوظة.

## تجهيز Netlify
من مجلد المصدر استخدم npm ci ثم npm run build. يتولى netlify.toml تحديد dist والتوجيه إلى وظائف الخادم. اضبط VITE_SUPABASE_URL وVITE_SUPABASE_ANON_KEY وSUPABASE_SERVICE_ROLE_KEY في إعدادات الموقع، والأخير للخادم فقط. طبق ترحيلات Supabase بالتسلسل حتى 0008_archo_owner.sql إذا لم تكن مطبقة. لا يوجد ترحيل جديد لهذا الإصدار. اختُبر البناء وتجميع الوظائف محليًا، وليس مشروع Netlify الحقيقي. راجع المتغيرات والوظائف وتسجيل الدخول وربط الشاشة في معاينة النشر قبل إصدار الإنتاج.

شغلت اختبارات الحسابات والصلاحيات والأخبار والتوقيت والواجهة على Chromium. ملف BAT نفسه لم يُشغّل داخل Windows في هذه البيئة.
